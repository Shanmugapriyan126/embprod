# Embroidery Production Dashboard (PWA)
1. Create a GitHub repo, upload all files here (keep the icons folder).
2. Settings > Pages > Deploy from branch > main / (root).
3. Open https://<username>.github.io/<repo>/ on your phone in Chrome > menu > Install app.
4. For an APK: paste that URL into https://www.pwabuilder.com > Package for Android.
